# 高配当株ポートフォリオ管理

日本株の高配当ポートフォリオを、取引台帳ベースで管理するブラウザアプリです。
スマホでも PC でも、同じ URL を開いて入力・閲覧できます。

**このリポジトリにはアプリのコードだけが入っています。**
資産データは利用者ごとの非公開リポジトリに保存され、ここには含まれません。

## できること

- **取引台帳** — 買付・売却・**株式分割**を日付つきで記録
- **自動計算** — 総平均法による平均取得単価、実現損益、含み損益
- **分散ルール** — 「1 セクター 20% 以下」「1 銘柄の配当 3% 以下」を判定し、買い増し余力を表示
- **ダッシュボード** — 配当受取カレンダー、セクター別構成、利回り分布
- **IRBANK 連携** — 配当履歴・業績・株価を毎日自動更新
- 明暗テーマの切り替え、CSV / JSON の入出力

## 使いはじめる

1. データ用の**非公開**リポジトリを作り、`portfolio.json` を置く
2. GitHub の Fine-grained personal access token を作る
   - 対象リポジトリ: **そのデータ用リポジトリだけ**
   - 権限: **Contents: Read and write** のみ
3. アプリを開き、「データ」タブから接続情報とトークンを入力

トークンはブラウザの localStorage にのみ保存され、GitHub 以外へは送信されません。

## 仕組み

```
ブラウザ (このアプリ)
    ↕ GitHub Contents API
非公開リポジトリ / portfolio.json
    ↑ 毎日 22:00 JST
GitHub Actions → IRBANK から株価・配当を取得
```

計算はすべてブラウザ内で完結します。サーバはありません。
保存のたびにコミットが積まれるため、変更履歴がそのままバックアップになります。

## 開発

ビルド不要です。素の ES モジュールで書かれています。

```bash
python3 -m http.server 8766
```

テストは `tests/` をブラウザで開くと実行されます。

## 注意

表示される数値は、記録した取引と IRBANK の公開情報に基づく計算結果です。
投資判断の助言ではありません。税務上の取得価額とも一致しない場合があります。
